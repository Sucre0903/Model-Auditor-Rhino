# 模型体检 Model Auditor 0.9.4

独立运行的 Rhino 8 模型负载诊断插件。用 `ModelAudit` 做只读体检，查看对象、图层和嵌套图块负载，并在 Rhino 中定位问题。可与屎壳郎插件同时安装。

## 0.9.4 安装修复

安装脚本先将项目源码复制到本机临时目录，再还原 NuGet 依赖并编译。原目录中的 `bin`、`obj` 和 `.vs` 不会进入构建。编译仍遇到 `NETSDK1064` 时，脚本会改用临时 NuGet 包目录重试一次。

## 0.9.3 功能

- 在「图层」页点击图层名即可选中行，再点击「选择」或「定位缩放」。结果包含所选图层上的直接物件，以及包含这些图层上块内物件的顶层实例。点「高亮」列中的 ↗ 可打开 Rhino 原生图层面板。
- 重点问题、物件、图层、图块和属性异常表均支持 Ctrl/Shift 多选。定位会合并结果并去重，隐藏或锁定物件继续使用临时轮廓示意。排序保留整组选中行。

## 0.9.2 功能

- 点击折叠分支内的图层时，先在 Rhino 原生面板中从外到内展开所属父级，再选中目标行。其他分支保留原有展开状态。
- 窄栏布局将「一键体检」和「停止」单独放一行，结果分类改为下拉，表格的图层列提前。其余列可横向滚动。

## 0.9.1 功能

- **原生图层高亮**。点击体检表格的图层链接，打开 Rhino 自带的「图层」面板，按图层 ID 高亮对应行。可用于隐藏或锁定图层，模型对象选择和当前建模图层保持原样。
- **侧边面板图标**。安装后随 Rhino 加载，首次有活动模型时将「模型体检」停靠在原生「图层」旁。之后由 Rhino 保存面板布局，点击图标即可打开。

## 0.9.0 功能

- **隐藏或锁定对象定位**。选择结果后点击「选择」或「定位缩放」。可选对象按原方式选中，其他可定位对象在当前视口以橙色轮廓框示意。超过 128 个示意对象时合并显示范围。对象及图层的可见性和锁定状态保持原样。
- **全表排序**。点击任意列标题切换升序和降序，内存、实例数和评分按原始数值排序。排序后保留选中的条目。
- **大模型扫描**。按时间分批读取对象，后台汇总和初始排序，结果表可查看完整数据。支持停止扫描，切换文档或隐藏、关闭面板时停止。对象、图层或块结构影响诊断时提示重新扫描。
- **诊断明细**。重点问题展示触发原因和关键数值。嵌套图块的实际实例链统计和顶层定位沿用 0.2.0 口径。

## 环境

- Windows 10/11 x64
- Rhino 8，使用 .NET 8 运行时。编译引用为 Rhino 8.28。内测建议使用 Rhino 8.28 或更新的 8.x 维护版。
- .NET 8 或更高版本的 SDK，首次还原需要访问 NuGet。运行 `dotnet --version` 确认 SDK 可用。已验证 .NET SDK 10.0.403 的 Release 编译。

## 安装与使用

1. 关闭 Rhino 8，将 ZIP 完整解压。若 Windows 文件属性中显示「解除锁定」，先解除锁定。
2. 双击 `1_一键构建安装.cmd`。脚本编译并为当前 Windows 用户注册插件。通过原脚本安装的版本使用同一个插件 GUID，升级后注册路径会指向 0.9.4。
3. 重启 Rhino 8，打开模型，点击侧边栏的「模型体检」图标，再点击「一键体检」。也可以从 Rhino 面板列表或 `ModelAudit` 命令打开。
4. 按数据列标题排序，点击图层链接在 Rhino 原生面板中高亮，也可选中一行或多行后使用「定位缩放」。工作完成后可点击「清除示意」或切换条目；「导出 CSV」保存完整对象和图块数据。

`2_仅构建.cmd` 用于本地编译，`4_源码约束检查.cmd` 用于检查只读约束。关闭 Rhino 后运行 `3_卸载插件.cmd`，可移除当前用户注册并将安装目录移到本机可恢复位置。

## 统计说明

- **已保存文件大小**读取磁盘上的 `.3dm`，未保存或无法访问时显示「不可用」。
- **估算内存**统计顶层对象、引用本身和图块定义。定义几何的估算值只计一次。
- **显示复杂度**优先使用已有渲染网格面数，其余以几何拓扑近似。体检保持模型几何、属性和撤销记录。用户主动定位时可改变选择状态、图层树展开状态或当前视口。
- 图块表的「自身累计负载」可跨定义相加。「单实例含子块」用于评估一个完整实例。块内问题定位关联的顶层实例。缺失定义、循环引用和实例数到达上限时会提示。
- 0.9.4 为内测源码版。真实 Windows Rhino 验收和「小而重」阈值校准见 `VALIDATION_中文.md`。
